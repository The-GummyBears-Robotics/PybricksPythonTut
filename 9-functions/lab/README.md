# `9-functions/lab/` — short box-bot practices

Use after the browser lesson [`teaching/functions-intro.html`](../../teaching/functions-intro.html). Each file is one focused exercise (~10–20 minutes); pick **one or two** in a follow-up session.

| File | Idea |
|------|------|
| `lab_drive_square_fn.py` | Multi-stage: square starter, then edge-length parameter, then triangle/pentagon/hexagon with polygon-angle hint. |
| `lab_victory_chirp.py` | Helper function with beeps after driving. |

Motors **A** / **B** and default `DriveBase` numbers match many SPIKE “box” builds — change ports or geometry if yours differs.
