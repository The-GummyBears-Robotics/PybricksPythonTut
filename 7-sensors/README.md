# Lesson 7: Sensors

Goal: read sensor values and use them to make robot decisions.

## Run These First

1. `distance-measure.py` - print and display ultrasonic distance.
2. `distance-stoprobot.py` - stop when an object is close.
3. `color-reflection.py` - read reflected light from the mat.
4. `color-stopatcolor.py` - drive until a target color is detected.
5. `menu-numbers.py` - choose behavior with hub buttons.

## Change One Thing

- Change the stop distance threshold.
- Change the target color.
- Change the robot speed while using a sensor.

## Sensor Habits

- Print raw sensor values before writing complicated logic.
- Move slowly when detecting a line or color.
- Keep sensor height and angle consistent.
- Test on the real mat, not only on the table.

## Challenge

Make the robot drive forward and stop at a line or mission model. It should stop because of a sensor reading, not because of a fixed time.
