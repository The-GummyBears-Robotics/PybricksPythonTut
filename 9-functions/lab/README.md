# `9-functions/lab/` — short box-bot practices

Use after the browser lesson [`teaching/functions-intro.html`](../../teaching/functions-intro.html). Each file is one focused exercise (~10–20 minutes); pick **one or two** in a follow-up session.

| File | Idea |
|------|------|
| `lab_drive_square_fn.py` | One function = one side of a square; call it four times. |
| `lab_victory_chirp.py` | Helper function with beeps after driving. |
| `lab_slow_if_close.py` | Function returns a speed from ultrasonic distance. |

Motors **A** / **B**, ultrasonic **C**, and default `DriveBase` numbers match many SPIKE “box” builds — change ports or geometry if yours differs.
