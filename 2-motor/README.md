# Lesson 2: Motor Basics

Goal: control one motor by speed, time, angle, and stall.

## Run These First

1. `motor_runs.py` - compare `run`, `dc`, `run_time`, `run_angle`, and `run_target`.
2. `motor_rotateangle.py` - rotate a motor by exact angles.
3. `motor_twotogether.py` - run two motors together.

## Change One Thing

- Change a speed number and observe what happens.
- Change `360` to `180` or `720` in an angle example.
- Try a negative speed or negative angle.

## Challenge

Build a simple attachment and make it:

- move up
- pause
- move down
- stop in a repeatable position

Use angle control when you want repeatability. Use stall only when the mechanism can safely hit an end stop.
