# Lesson 9: Functions

Goal: turn repeated robot actions into named steps.

## Run These First

1. `fun-base.py` - define a function and call it twice.
2. `fun-inputs.py` - pass values into a function.
3. `fun-returns.py` - return a value from a function.
4. `fun-sensor.py` - put sensor logic inside a function.

## Change One Thing

- Rename a function so it describes the action clearly.
- Add a parameter for speed, distance, count, or color.
- Call the same function with two different inputs.

## Good Function Names

Use names that sound like robot actions:

- `drive_to_line`
- `lift_attachment`
- `drop_model`
- `return_home`

## Challenge

Take one drivebase or sensor program and split it into 2-3 functions. The main part of the file should read like a short mission plan.
